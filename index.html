This is a JavaScript implementation of the game Fringer, which was designed by Alexey Pajitnov and released in Microsoft Entertainment Pack: The Puzzle Collection in 1997.

Use the left and right arrow keys to move the cursor and space or 'X' to twist. Untie knots by matching the cursor's direction to the upper rope and then twisting. Every few seconds, the knots will be pushed down and new knots will appear at the top. If any knots reach the bottom, you lose.

Press 'P' to pause. Press 'N' at any time to start a new game, or enter a level number at any time to start that level.

Boosts allow you to switch the direction of the cursor. Untangle knots with sparkles to gain boosts. Press tab or the down arrow to use them.
