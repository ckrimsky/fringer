This is a JavaScript implementation of the game Fringer, which was designed by Alexey Pajitnov and released in Microsoft Entertainment Pack: The Puzzle Collection in 1997.

Use the left and right arrow keys to move the cursor and space to twist. Untie knots by matching the cursor's direction to the upper rope and then twisting. Every few seconds, the knots will be pushed down and new knots will appear. If any knots reach the bottom, you lose. Press 'P' to pause. Press 'N' at any time to start a new game.
