This is my own implementation of the game Fringer designed by Alexey Pajitnov. It is playable online [here](https://ckrimsky.github.io/fringer/).

This version includes the same levels and scoring. I've tried to match the behavior for generating knots, sparkles, and the candle bonus, and the timing of knots descending. This version of the paintbrush bonus differs from the original, which appeared at the start of the first stage of every other level (starting at 3-1).

I currently have no plans to implement the bar slowly pushing knots down the screen.

Origininal sound effects retreived from [The Sounds Resource](https://sounds.spriters-resource.com/pc_computer/microsoftentertainmentpackthepuzzlecollection/asset/438174/). Original soundtrack with Windows sound font recorded by [Aydos Barbados on Youtube](https://www.youtube.com/playlist?list=PLwi903AXkHEvjcLyNydPVFixkHvEs4mi3).

Colorblind-friendly palettes found [here](https://conceptviz.app/tools/colorblind-friendly-palettes), and my created palettes were tested using their checker.
