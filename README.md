This is my own implementation of the game Fringer designed by Alexey Pajitnov. It is playable online [here](https://ckrimsky.github.io/fringer/).

This version includes the same levels and scoring. I've tried to match the behavior for generating knots, sparkles, and the candle bonus, and the timing of knots descending. This version of the paintbrush bonus differs from the original, which appeared at the start of the first stage of every other level (starting at 3-1).
