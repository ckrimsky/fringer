This is an implementation of the 1997 game Fringer, designed by Alexey Pajitnov, and released in Microsoft Entertainment Pack: The Puzzle Collection. Currently this implementation only has an arcade mode.

Use the left and right arrow keys to move the cursor and space to twist. Untie knots by matching the cursor's direction to the knot and then twisting. Every few seconds, straightened ropes will be cleared the knots will be pushed down. If any knots reach the bottom, the game is over. Press 'n' to start a new game.
